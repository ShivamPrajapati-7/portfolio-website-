Transparenzy

An Android emergency safety application that instantly sends the user’s live GPS location to pre-saved emergency contacts through SMS. The app can be activated using a shake gesture combined with the volume-up button, providing quick emergency assistance during critical situations.

Project Overview

Transparenzy is designed to provide immediate emergency support when a user is unable to make a phone call manually. The application focuses on speed, accessibility, and reliability by allowing an SOS alert to be triggered through simple physical gestures.

Key Features

  • Instant SOS emergency SMS alerts
  • Live GPS location sharing
  • Google Maps location link generation
  • Shake gesture detection using accelerometer sensors
  • Volume-up button emergency activation
  • Save up to 5 emergency contacts
  • Offline functionality using SMS service
  • Simple and lightweight user interface

Application Workflow

  1. User adds emergency contacts.
  2. Contacts are stored locally on the device.
  3. User shakes the phone while pressing the volume-up button.
  4. The app retrieves the current GPS coordinates.
  5. An SOS message is generated automatically.
  6. The message is sent to all saved emergency contacts.

Tech Stack

  • Kotlin - Android development
  • Android Studio - IDE
  • Fused Location Provider - GPS tracking
  • SmsManager API - SMS communication
  • SensorManager API - Shake detection
  • SharedPreferences - Local data storage
  • Material Design - UI components

Challenges Solved

  • Handling Android runtime permissions for SMS and location
  • Detecting shake gestures without false triggers
  • Combining hardware button events with sensor events
  • Managing location updates efficiently to reduce battery usage
  • Ensuring SMS delivery even without internet connectivity

Future Improvements

  • Real-time location tracking
  • Firebase cloud synchronization
  • Voice-command SOS activation
  • Wearable device integration
  • Emergency service integration
