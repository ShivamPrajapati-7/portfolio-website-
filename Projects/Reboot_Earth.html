🌱 Reboot Earth — AI-Powered Waste Classification

Small steps for a greener planet.

Reboot Earth is an Android application that uses machine learning to classify waste from images and provide disposal guidance and recycling steps. It aims to help users make better waste-segregation decisions and encourage responsible waste management.

The application uses a custom-trained EfficientNetB0 model converted to TensorFlow Lite for on-device image classification.

Project Overview

Reboot Earth helps users identify broad waste categories by capturing a photo or selecting an image from their gallery. The app displays a predicted category, confidence score, disposal guidance, and recycling steps. The current prototype classifies waste into four categories and runs inference locally using TensorFlow Lite.

📱 Features

1. 📷 Image Capture and Selection

  • Camera Support: Capture a photo of a waste item using the device camera.
  • Gallery Support: Select an existing image from the device gallery.
  • Image Preview: Review the selected image before classification.

2. 🧠 AI Waste Classification

  • EfficientNetB0: A custom classification head trained on a pretrained EfficientNetB0 feature extractor.
  • TensorFlow Lite: Runs the exported model locally on the Android device without a cloud inference API.
  • Four Waste Categories: Hazardous, Non-Recyclable, Organic, and Recyclable.
  • Confidence Score: Displays the model's confidence for its predicted category.

3. ♻️ Disposal Guidance and Recycling Steps

  • Category-Specific Guidance: Shows disposal recommendations based on the predicted category.
  • Recycling Steps: Provides numbered actions to help users sort or dispose of waste appropriately.
  • Safety Considerations: Hazardous items may require specialized handling and authorized collection.

🧠 AI Model and Performance

The model was trained with TensorFlow/Keras using transfer learning. The pretrained EfficientNetB0 feature extractor was frozen during the initial training stage, and a new four-class classification head was trained.

Model Details

  • Architecture: EfficientNetB0
  • Input Shape: 224 × 224 × 3
  • Input Type: float32
  • Output Shape: [1, 4]
  • Output Activation: Softmax
  • Export Format: TensorFlow Lite (.tflite)
  • Model Size: Approximately 15.34 MB
  • Dataset: 2,917 images
  • Validation Split: 80% training / 20% validation

Supported Categories

  • Hazardous: Waste that may require special handling or authorized collection.
  • Non-Recyclable: Waste not accepted by the relevant recycling stream.
  • Organic: Organic waste, such as suitable food scraps.
  • Recyclable: Materials that may be recyclable under local rules.

Validation Results

The initial model achieved approximately 78% validation accuracy on 584 validation images.

Application Workflow

  1. Open Reboot Earth.
  2. Capture a waste image with the camera or select an image from the gallery.
  3. Preview the image and tap Identify Waste.
  4. The TensorFlow Lite model predicts one of the four waste categories.
  5. View the predicted category and confidence score.
  6. Read the disposal guidance and category-specific recycling steps.
  7. Follow local waste-management rules and verify instructions for potentially hazardous items.

🚀 Running the Android Project

  1. Clone the repository into Android Studio.
  2. Ensure the trained model is located at app/src/main/assets/waste_classifier.tflite.
  3. Ensure the class labels are located at app/src/main/assets/class_names.json.
  4. Sync Gradle dependencies.
  5. Build and run the application on a compatible Android emulator or physical device.

🔬 Model Training

The model was trained using a public waste-classification dataset downloaded with KaggleHub.

Dataset source: PhenoMSg — Waste Classification on Kaggle

  1. Load and inspect the dataset.
  2. Split images into training and validation sets using an 80/20 split.
  3. Resize images to 224 × 224.
  4. Load ImageNet-pretrained EfficientNetB0.
  5. Train a four-class classification head.
  6. Evaluate accuracy, precision, recall, F1-score, and the confusion matrix.
  7. Convert the trained model to TensorFlow Lite.

The exported model expects RGB image pixels in the 0–255 range. Android preprocessing must match the preprocessing used during training.

⚠️ Limitations & Safety

  • The current model predicts four broad categories and does not identify every individual material or object.
  • The validation accuracy of approximately 78% means incorrect predictions are possible.
  • A high confidence score does not guarantee a correct result.
  • Hazardous waste should not be handled based solely on an AI prediction.
  • Disposal recommendations should be checked against local waste-management rules.
  • The app is not a substitute for professional hazardous-waste identification or handling advice.
